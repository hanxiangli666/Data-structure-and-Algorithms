# Data Structure and Algorithms

A multi-language algorithms and competitive-programming practice repository covering C++, Java, Python, Go, JavaScript, ICPC notes, LeetCode practice, and small AI-agent experiments.

## Purpose

This repository documents my foundations in data structures, algorithmic thinking, and implementation practice across languages. It is designed as long-term proof that I can write core algorithms by hand, reason about complexity, and translate concepts between languages.

## Main Areas

```text
C++/          Core syntax, STL, vectors, stacks, queues, maps, sets, OOP notes
Golang/       Slices, maps, linked-list/queue-style container practice
Java/         Java data-structure and algorithm exercises
JavaScript/   JavaScript algorithm practice
Python/       Python implementations and exercises
ICPC/         ICPC notes, C++ practice, LeetCode, Luogu problems
AI_agent/     Small agent experiment with tests
```

## Evidence

The repository includes:

- C++ STL and data-structure implementations.
- ICPC and LeetCode practice files.
